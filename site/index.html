Using the explorer

  • Building views. Switch between all years, fall migration, spring migration and the last 5 years in the Layers panel. Colour is birds reported; height is the building's height.
  • Report points are split into three eras (1996–2013, 2014–2020, 2021–2026); the latest is on by default. Each era has filters for species (type part of a name, e.g. “warbler”), outcome, season, year and monitoring group. Set a filter on each era you have switched on.
  • Bookmarks jump to cities with the most reports. Click a building or point for details.
  • Building totals in the explorer are fixed per view; they don't change when you filter the points.

Data

  • buildings.parquet: one row per building, with totals for every view
  • reports.parquet: every published report
  • bird-collisions.geolibre: the GeoLibre project (open it in GeoLibre's desktop or web app)

GeoParquet files open in QGIS, DuckDB, GeoPandas and GeoLibre.

About the data

  • Reports, not risk. Counts reflect where volunteers looked as much as where birds died. Most reports come from Toronto, where monitoring has run the longest; a building with no reports may never have been checked.
  • Attribution. Each report is assigned to the nearest building footprint within 25 m.
  • Privacy. Reports at private homes, and reports with no building footprint nearby, are not shown.
  • Heights come from Overture Maps, using the tallest tower section where one is modelled; buildings with no height data are drawn at 6 m.
